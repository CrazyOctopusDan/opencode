# Coding Workflow

1. Identify the runtime path that owns the behavior.
2. Add or update focused tests for risky behavior changes.
3. Make the smallest code change that satisfies the test and preserves existing behavior.
4. Run focused verification, then broader checks if the touched surface is shared.
5. Report exact verification results and any remaining risk.
